# lowfi : musique lo-fi dans le terminal

## Lancer
    lowfi                        lecture en continu
    lowfi -p                     démarrer en pause
    lowfi -m                     sans la barre des touches
    lowfi -c                     avec une horloge
    lowfi -t bookmarks           les morceaux mis en favoris

## Touches
    s  n  l                      morceau suivant
    p  Espace                    pause / lecture
    +  ↑  k  /  -  ↓  j          volume ±10 %
    →  /  ←                      volume ±1 %
    b                            favori (ou retirer des favoris)
    q  Ctrl-c                    quitter

## Exemple
    Dans un volet tmux : P %  puis  lowfi -m  , et travailler dans l'autre volet.
