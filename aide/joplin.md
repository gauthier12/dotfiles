# Joplin : notes en Markdown, synchronisées

## Indispensables
    Ctrl-p                       aller à une note, un carnet, une étiquette (par son nom)
    Ctrl-Maj-p                   palette de commandes
    Ctrl-n / Ctrl-t              nouvelle note / nouvelle tâche
    F6                           recherche dans toutes les notes ;  Ctrl-f : dans la note
    Ctrl-s                       synchroniser
    Ctrl-Alt-t                   étiquettes de la note
    Ctrl-l                       changer de disposition (éditeur, aperçu, les deux)
    Ctrl-Alt-e                   basculer éditeur Markdown / éditeur visuel
    F10 / F11                    masquer la barre latérale / la liste des notes
    Ctrl-,                       options (synchronisation, thème…)

## Écrire
    Ctrl-b  Ctrl-i  Ctrl-`       gras, italique, code
    Ctrl-k                       lien
    Alt-Maj-l                    lien vers une autre note
    Ctrl-Maj-t                   insérer la date et l'heure
    - [ ] tâche                  case à cocher (Markdown)

## Exemple
    Ctrl-p  « courses »  Entrée  : ouvre la note, quel que soit son carnet.

Thème : Options → Apparence (Joplin a ses propres thèmes clair et sombre).
