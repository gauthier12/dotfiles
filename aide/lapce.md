# Lapce : éditeur graphique

Thèmes Catppuccin installés : palette de commandes, « color theme », pour changer de variante.
Langages : panneau des plugins (Ctrl-Maj-x), chercher le langage (« rust », « python », « typst ») et installer.

## Indispensables
    Ctrl-Maj-p  ou  F1           palette de commandes (toutes les actions)
    Ctrl-p                       ouvrir un fichier du projet par son nom
    Ctrl-g                       aller à la ligne
    Ctrl-Maj-o / Ctrl-t          symbole du fichier / du projet
    Ctrl-s   Ctrl-n   Ctrl-w     enregistrer, nouveau fichier, fermer
    Ctrl-,                       réglages ;  Ctrl-k Ctrl-s : raccourcis

## Édition
    Ctrl-d                       sélectionner l'occurrence suivante (curseurs multiples)
    Ctrl-Alt-↑ / ↓               ajouter un curseur au-dessus / dessous
    Alt-↑ / Alt-↓                déplacer la ligne
    Alt-Maj-↑ / ↓                dupliquer la ligne
    Ctrl-/                       commenter
    Ctrl-] / Ctrl-[              indenter / désindenter
    Ctrl-l                       sélectionner la ligne

## Code (avec un plugin de langage)
    Ctrl-Espace                  complétion
    F12                          aller à la définition ;  Ctrl-- : revenir
    F2                           renommer le symbole
    Ctrl-.                       actions proposées (corrections)
    F8 / Maj-F8                  erreur suivante / précédente
    Ctrl-Maj-m                   liste des problèmes

## Panneaux
    Ctrl-Maj-e                   explorateur de fichiers
    Ctrl-Maj-f                   chercher dans le projet
    Ctrl-`                       terminal
    Ctrl-\                       couper l'éditeur en deux

Touches de vim : réglage « Modal » dans Ctrl-, (désactivé par défaut).
